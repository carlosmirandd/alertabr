# Código de conduta

Adaptado do [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Queremos um espaço respeitoso e acolhedor para todas as pessoas, independentemente de idade, deficiência, etnia, gênero, identidade, experiência, nacionalidade, aparência, religião ou orientação.

**Esperamos:** respeito e empatia, crítica construtiva, assumir erros e aprender com eles, foco no que é melhor para a comunidade.

**Não toleramos:** assédio, insultos, ataques pessoais, divulgação de dados privados de outras pessoas, linguagem ou imagens sexualizadas e qualquer conduta que seria considerada inadequada em um ambiente profissional.

Este é um projeto técnico sobre dados públicos de alerta. Discussões partidárias fora do escopo do projeto serão encerradas.

**Aplicação:** quem mantém o projeto pode editar ou remover comentários, issues e PRs que violem estas regras e, em casos graves, bloquear a pessoa. Para reportar um problema de conduta, use um aviso privado em *Security → Report a vulnerability* ou fale com quem mantém o repositório pelo perfil do GitHub.
